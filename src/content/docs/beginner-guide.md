> 不需要会编程。只要你能安装软件、会复制粘贴，就能跟着走完。
> 每一步都写了「✅ 成功是什么样」和「❌ 失败怎么办」。

## 这是干什么的

你的 NAS 里是不是堆了好几年的东西：手机自动备份的照片、下载完就忘的文件、
八个「最终版」的工作文档……

这个项目会给你的 **AI 助手**（比如 Claude Code）装上一套「整理说明书」，
然后你只要对它说一句：

> 「帮我把 NAS 里的照片按日期整理好」

AI 就会先扫描、列一份计划给你过目，**你点头它才动手**。

## 先吃三颗定心丸

1. **扫描只读** —— 所有整理的第一步都是「只看不动」，先出一份报告
2. **确认才动手** —— AI 必须先给你看「旧名字 → 新名字 / 移到哪」的清单
3. **删除先隔离** —— 建议删除的文件会先挪进隔离文件夹，你看过才真删

## 你需要准备什么

- [ ] 一台 NAS（极空间 / 群晖 / 威联通 / 绿联都行）
- [ ] 一台电脑（本指南以 **Mac** 为例）
- [ ] 一个 AI 助手：Trae（免费、中文界面）、Claude Code、Cursor 任选
- [ ] 15–30 分钟

## 只解释 4 个名词

| 名词 | 大白话 |
|---|---|
| NAS | 家里那台存东西的「网络硬盘盒子」 |
| 终端 | Mac 上打字执行命令的窗口（⌘+空格 搜「终端」） |
| 命令 | 复制粘贴到终端、按回车执行的一行字 |
| Skill | 给 AI 看的「说明书」，装了它 AI 才会整理文件 |

## 四步走完

### 第 1 步：装 zspace-cli

```bash
pip install zspace-cli
zs check
```

✅ 看到 `✓ 已连接极空间客户端` 就成功了。

### 第 2 步：装技能

```bash
mkdir -p ~/nas-helper
zs skill ~/nas-helper/skills/
```

### 第 3 步：打开 AI 助手

在 `~/nas-helper` 目录下打开你的 AI 助手（Trae / Claude Code / Cursor）。

### 第 4 步：说人话

> 「先读一下 skills 目录里的说明，然后帮我扫描 `/sata11/my/data/照片`，
> 按拍摄日期给一份整理计划，**先别动手**。」

✅ 成功：AI 会给你一份表格，列出「哪个文件 → 移到哪」。

你只要回一句「确认」，它才执行。

## 常见问题

**Q：会不会把我的文件搞丢？**

不会。所有整理都是「移动」不是「删除」，而且删除会先进隔离文件夹。
即使 AI 判断错了，你也可以一条命令移回去。

**Q：会不会把我的数据传到网上？**

不会。zspace-cli 只在你本机运行，数据不经过任何服务器。

**Q：我不是极空间，能用吗？**

能。9 个整理技能是跨品牌的，走 SMB 挂载就行 —— 见[集成指南](/integrations/)。
